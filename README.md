# Technology News & Blogs

A responsive multi-page website built with **HTML, Tailwind CSS v4 (compiled locally with `@tailwindcss/cli`), and vanilla JavaScript**.

## How to run it
This version compiles Tailwind for real instead of loading it from a CDN, so it needs Node.js installed once.

```
npm install
npm run build
```

Then open `src/index.html` in your browser. While you're actively editing classes, run this instead so `src/output.css` rebuilds automatically every time you save a file:

```
npm run watch
```

## How the styling works
- `src/input.css` is the source stylesheet: `@import "tailwindcss";` plus this project's own design tokens, written in Tailwind v4's CSS-first `@theme` syntax.
- `src/output.css` is the **compiled** stylesheet the HTML pages actually link to (`<link rel="stylesheet" href="output.css">`). It is generated by the build command above — don't edit it by hand, your edits will be overwritten on the next build.
- `@theme` in `input.css` defines the project's design tokens so Tailwind recognizes them as real classes:
  - Colors: `bg-navy` `#171A2B`, `bg-purple` `#6C3FA0` (plus `purple-900/800/500/300/100` shades), `bg-lavender` `#F7F3FC`, `text-cyan` `#4CC9F0`, `text-ink` `#242124`, `text-muted` `#6B6870`, `text-err` `#B3261E`.
  - Fonts: `font-head` (Poppins, for headings) and `font-body` (Inter, for everything else).
- A handful of plain `@keyframes` (`hero-in`, `feed-in`, `float-blob`, `pulse-dot`, `pulse-dot-purple`) power the small entrance/glow animations, used via Tailwind's arbitrary `animate-[...]` syntax in the HTML.
- `@plugin "@tailwindcss/typography";` in `input.css` adds the `prose` classes used to style the article body text.
- Custom breakpoints from the original design (820px for the mobile menu, 640/760/960/1120px elsewhere) are written as Tailwind arbitrary variants, e.g. `min-[821px]:flex`.

## Pages
| File | What it is |
| --- | --- |
| `src/index.html` | Home: hero, stats strip, "why this site" features grid, latest news, categories, blogs, newsletter |
| `src/news.html` | All news with search, category filter, sorting and "Show more" |
| `src/blogs.html` | All blog posts with the same tools |
| `src/categories.html` | Category overview. Pick one to list its articles |
| `src/article.html` | Article details. Opens any article with `article.html?id=ARTICLE-ID` |
| `src/about.html` | About the site and a contact form |

## Folders
- `src/js/data.js` holds all categories and articles. **Add or edit articles here.**
- `src/js/main.js` has shared code: icons, generated cover artwork, the Tailwind-classed card/row/tile templates, the mobile menu, scroll-reveal animation, count-up numbers and the back-to-top button.
- `src/js/home.js`, `listing.js`, `categories.js`, `article.js`, `contact.js` each run one page and inject Tailwind-classed markup via the shared templates in `main.js`.

## Add a new article
Open `src/js/data.js`, copy an existing article object inside `ARTICLES`, give it a new unique `id`, and change the text. It appears on the home page, listings, categories and its own article page automatically — no HTML or CSS to touch.

## Things to replace
- The articles are sample content written for this project. Replace them with your own.
- The cover images are drawn by JavaScript. To use real photos, change the `.aspect-video` cover markup in `js/main.js`.
- The newsletter and contact forms check the input but do not send anything yet. Connect them to a form service or backend.
